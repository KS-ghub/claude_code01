# IPパッケージ：IoTセンサー×予知保全パッケージ（IP-PKG-002）

## 概要

回転機器（モーター、ポンプ、コンベア等）に取り付けた振動・温度・電流センサーのデータをエッジ側で一次処理し、故障予兆を統計的に検知して保全担当者にアラートを送る技術一式。計画外停止（ダウンタイム）の削減と保全コストの最適化を目的とする。
