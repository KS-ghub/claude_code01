# IPオファリング：知財契約

## 概要

IPパッケージ（特許・ノウハウ・ソフトウェア）を社外に開示・提供する際に必要な契約類型（NDA、ライセンス契約、OEM供給契約、共同研究開発契約、業務委託契約の知財条項等）を設計・レビューする。既存契約の用途制限との整合性確認も担う。

## 提供内容（標準ステップ）

1. **取引スキーム整理**：誰に・何を・どこまで開示するかを事業部とともに整理
2. **既存契約との整合性チェック**：対象IPパッケージに既存の開示先限定・用途制限がないか確認
3. **契約類型選定**：NDA単独か、ライセンス契約が必要か、OEM契約か等を判断
4. **契約書ドラフト・交渉支援**：契約書の作成、相手方との条件交渉に同席
5. **締結後の管理登録**：締結契約をIPパッケージ台帳の「関連契約」節に反映

## 提供トリガー（いつ使うか）

- 事業部がIPパッケージを使った新製品・サービスを外部顧客に提供しようとしているとき
- 既存契約の用途制限に抵触する可能性がある新規提案が出てきたとき（[[product-development-agent]] のSTEP3で検出された場合など）
- 業務委託先にノウハウ文書を開示する必要があるとき

## 成果物

- 契約書ドラフト・締結版
- 既存契約との抵触チェック結果
- IPパッケージ台帳への契約情報反映

## 標準所要期間

NDA単独：1週間程度／ライセンス・OEM契約：交渉状況により1〜3ヶ月
