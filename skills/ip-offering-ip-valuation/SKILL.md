# IPオファリング：知財価値評価

## 概要

IPパッケージまたは個別の特許・ノウハウの経済的価値を、インカムアプローチ（将来収益の割引現在価値）、マーケットアプローチ（類似取引比較）、コストアプローチ（開発コスト積み上げ）等の手法で評価する。ライセンス料率設定や社内投資判断の客観的根拠として用いる。

## 提供内容（標準ステップ）

1. **評価目的の確認**：ライセンス料率設定か、投資判断か、M&Aデューデリジェンスかで手法を選定
2. **対象IPの実績データ収集**：使用実績・使用用途、既存契約のロイヤリティ実績などIPパッケージ台帳から収集
3. **評価モデル構築・算定**：選定手法に基づき価値レンジを算出
4. **評価レポート作成**：前提条件・感度分析を含むレポートを作成
5. **意思決定支援**：経営会議・事業部への説明資料化

## 提供トリガー（いつ使うか）

- ライセンス契約の料率交渉が必要なとき（[[ip-offering-ip-contract]] と連動）
- 新規IPパッケージへの追加開発投資の可否を社内で判断するとき
- IPパッケージを含む事業譲渡・M&Aの検討が生じたとき

## 成果物

- 知財価値評価レポート（評価額レンジ、前提条件、感度分析）
- ライセンス料率提案（該当する場合）

## 標準所要期間

簡易評価：1〜2週間／詳細評価（M&A等）：1〜2ヶ月

## 担当窓口

知財部 価値評価グループ（ip-valuation@example-internal.com）
