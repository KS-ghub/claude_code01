# IPパッケージ：需要予測・在庫最適化AIパッケージ（IP-PKG-003）

## 概要

POSデータ・気象データ・イベント情報などの外部要因を組み込んだ需要予測モデルにより、店舗・倉庫単位での最適発注量を算出する技術一式。欠品による機会損失と過剰在庫による廃棄・保管コストの両方を削減することを目的とする。

## 構成資産

### 特許

| No | 発明の名称 | 出願番号 | 登録番号 | 請求項要旨 |
|----|-----------|---------|---------|-----------|
| P-5 | 外部要因変数の動的重み付けによる需要予測方法 | 特願2022-XXXXX5 | 特許第7XXXXX5号 | 気象・イベント等の外部要因の予測寄与度を商品カテゴリごとに動的に重み付けし直す方法発明。新商品・季節商品の予測精度を従来比で改善。 |

| No | 名称 | 概要 | 保管場所 |

### ソフトウェア

- **名称**: DemandSense API
- **リポジトリ**: 社内GitLab `retail/demand-sense-api`
- **機能**: 需要予測モデルの学習・推論・発注量算出をREST APIとして提供。BIツール連携用のダッシュボードテンプレート付き。
- **技術スタック**: Python (LightGBM, Prophet), FastAPI, PostgreSQL
- **ライセンス形態**: 社内利用は無償、社外提供時は別途ライセンス契約が必要

## 使用実績・使用用途

- 自社小売子会社G社の全店舗（120店舗）に導入済み、欠品率を約20%削減、廃棄ロスを約15%削減
- 2025年、卸売パートナーH社にAPI提供開始（下記契約C-5）
- 想定用途：小売店舗の自動発注、製造業の生産計画連動在庫管理、EC事業者の需要予測（要データ連携追加開発）
