# IPシナリオ：外部OEM・ライセンス提供型

## 概要

自社IPパッケージを外部の取引先・パートナー企業にOEM供給、またはソフトウェア・特許ライセンスとして外販するシナリオ。[[ip-scenario-ip-package-cross-offering]]（社内での組み合わせ提供）と異なり、相手が社外であるため、目的外利用・第三者への再許諾・技術流出のリスク管理がより重要になる。

## 想定シーン

- 事業部・営業部門から「取引先にこの検査技術をOEM供給したい」という相談があったとき（IP-PKG-001のC-1契約のような事例）
- 既存パートナーとのPOC（実証実験）が成功し、商用ライセンス契約への移行を検討するとき（IP-PKG-002のC-3契約のような事例）

## 組み合わせるIPオファリング（順序）

| 順序 | オファリング | タイミング（目安） |
|---|---|---|
| 1 | [[ip-offering-knowhow-protection]] ノウハウの特定・保護（開示範囲の再確定） | 外部提供検討開始時 |
| 2 | [[ip-offering-ip-valuation]] 知財価値評価（ロイヤリティ・供給価格の算定根拠） | 開示範囲確定後 |
| 3 | [[ip-offering-ip-contract]] 知財契約（OEM供給契約／ライセンス契約の設計・締結） | 価格・条件合意後 |
| 4（運用フェーズ） | [[ip-offering-ip-contract]] 知財契約（契約更新・監査） | 契約期間中、定期的に |

## 事業部との関与タイミング

- **検討開始時**：どこまでの技術・ノウハウを開示可能かを知財部と事業部で事前合意（開示レベルの線引き）
- **契約締結前**：価値評価に基づく条件交渉、契約書ドラフトレビュー
- **契約締結後**：相手先の利用範囲逸脱（再許諾・目的外利用）がないかの定期モニタリング。IPパッケージ台帳の「関連契約」節を常に最新化

## 成果物

- 開示範囲定義書
- 価値評価レポート（ロイヤリティ・供給価格根拠）
- OEM供給契約／ライセンス契約
- 定期モニタリング記録

## 留意事項

- 契約終了後の技術返還・使用停止義務を契約に明記すること
- POC（実証実験）段階のゆるい契約のまま商用提供に移行しないよう、[[ip-offering-ip-contract]] で契約類型の切り替えを必ず確認する（IP-PKG-002のC-3契約のように、POC契約は商用利用を想定していないケースが多い）
