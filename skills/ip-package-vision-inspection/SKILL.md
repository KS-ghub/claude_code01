# IPパッケージ：画像認識検品システム（IP-PKG-001）

## 概要

工場の製造ラインにおいて、カメラ画像から製品表面の傷・異物混入・寸法不良をリアルタイムに検出する技術一式。従来は目視検査に依存していた工程を自動化し、検査精度と歩留まりを両立させることを目的に開発された。少量の学習データでも高精度を出せる独自の前処理・転移学習手法が核。

### ソフトウェア

- **名称**: VisionInspect Core SDK
- **リポジトリ**: 社内GitLab `manufacturing/vision-inspect-core`
- **機能**: 画像取得・前処理・推論・結果判定APIを提供するC++/Pythonライブラリ。エッジデバイス（Jetson系）およびサーバー推論の両対応。
- **技術スタック**: OpenCV, PyTorch, ONNX Runtime, gRPC
- **ライセンス形態**: 社内利用は無償、社外提供時は別途ライセンス契約が必要（下記契約参照）
